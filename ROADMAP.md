# Roadmap

The roadmap is intentionally conservative. Reliability and understandable behavior take priority over adding many overlapping controls.

## Near Term

- Expand mixed-DPI and large-group manual coverage for multi-monitor restoration.
- Add optional import-library editing and cache cleanup tools.
- Extend keyboard-accessible selection with more bulk operations in the Hub.
- Expand automated coverage around import limits and persistence migration.

## Later

- Named layout profiles for collections of images.
- Optional animated GIF playback without regressing large-collection performance.
- Localization architecture beyond the current English UI and Japanese documentation.

Roadmap items are proposals, not promises. Accepted work is tracked through GitHub Issues and pull requests.

## Delivered In 1.4.0

- Grouped movement and scaling with persistent membership.
- Autosave, validated backup recovery, and single-instance Hub activation.
- Per-monitor off-screen recovery that preserves group spacing.
- Unavailable registrations with retry and relinking instead of silent removal.
