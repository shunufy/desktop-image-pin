# Desktop Image Pin

[English README](README.md)

Desktop Image Pinは、画像を透明・枠なしの独立ウィンドウとしてWindowsデスクトップへ直接配置するツールです。資料作成中の参照画像、配信画面の飾り、視覚的なメモ、切り抜き画像、デスクトップ装飾などを、通常の画像ビューアの枠や単一キャンバスに縛られず表示できます。

一般的な画像ビューアとの違いは、各画像が独立して移動・拡大縮小・前後関係変更・クリック透過・変形・複製・復元できる点です。Hubから多数の画像をまとめて管理しつつ、表示画像そのものにはタイトルバーや枠を出しません。

![Desktop Image PinのHub画面](docs/images/hub.png)

スクリーンショットは以前のバージョンです。v1.4ではグループ化・再表示・画面外救出の操作も追加されています。

## 主な機能

- 複数画像を透明・枠なしウィンドウとして表示
- 左ドラッグ移動、ホイール拡大縮小
- 複数画像をグループ化し、画像間隔を保ったまままとめて移動・拡大縮小
- `Ctrl + ホイール`で横幅のみ、`Alt + ホイール`で高さのみ変更
- 大きな画像を初回表示時に作業領域の90%以内へ自動縮小
- 画像ごとの最前面・通常・背面表示
- クリック透過、透明度、90度回転、左右・上下反転
- 画像変更、複製、個別削除、全削除
- 複数ファイルのドラッグ＆ドロップ
- クリップボードとHTTP/HTTPS URLからの取り込み
- 名前付きURL画像をローカル保存し、毎回取得せず再利用
- 位置、縦横の拡大率、前後関係、透明度、変形、クリック透過を復元
- 操作停止から約1.5秒後に自動保存し、正常な設定を1世代バックアップ
- 読めない画像も「Unavailable」として登録を保持し、再表示・ファイル変更に対応
- モニターごとの作業領域へ画面外画像を救出し、グループの並びを保持
- タスクトレイ常駐
- 二重起動時は既存のHubを表示
- Windows起動時の自動起動
- `Ctrl + Shift + H`でHubを表示・非表示
- Hubに現在の表示枚数を表示

## 対応画像形式

PNG、JPEG、BMP、GIF、TIFFに対応します。GIFは先頭フレームのみ表示します。URL画像は25MBまでで、応答本文の受信を含めて30秒の制限があります。失敗したダウンロードの部分ファイルは削除します。

## インストール

1. [最新のGitHub Release](https://github.com/shunufy/desktop-image-pin/releases/latest)から`DesktopImagePin.exe`をダウンロードします。
2. 任意のフォルダーへ配置します。
3. 起動中の旧版を終了してから、EXEをダブルクリックします。

配布EXEはWindows x64向け自己完結型なので、.NETランタイムの別途インストールは不要です。

更新時は、EXEの置換・起動前にHubまたはタスクトレイの**「Exit」**で完全終了してください。Hub右上の**「×」は非表示にするだけ**で、アプリは動き続けます。トレイアイコンが消えてから旧EXEを置き換え、新版を起動します。旧版が動いている間に新版を起動すると、旧版のHubが再表示されます。

## ソースから起動

Windows 10または11と.NET 8 SDKが必要です。

```powershell
git clone https://github.com/shunufy/desktop-image-pin.git
cd desktop-image-pin
dotnet restore DesktopImagePin.sln
dotnet run --project DesktopImagePin.csproj
```

## 操作方法

| 操作 | 方法 |
| --- | --- |
| 画像移動 | 左ドラッグ |
| 画像メニュー | 右クリック |
| 縦横比を保って拡大縮小 | マウスホイール |
| 横幅のみ変更 | `Ctrl + マウスホイール` |
| 高さのみ変更 | `Alt + マウスホイール` |
| 複数画像の選択 | Hubで`Ctrl`または`Shift`を押しながら行を選択 |
| グループ化 | 2枚以上を選択して「Group」 |
| グループ解除 | グループ内の画像を選んで「Ungroup」、または画像の右クリックメニュー |
| 画面外画像の救出 | Hubの「Recover Off-screen」 |
| 未表示画像の再表示 | 対象行の「Retry」、移動したファイルは「Change」で指定 |
| Hub表示切り替え | `Ctrl + Shift + H` |
| Windows起動時に自動起動 | Hubの「Start Desktop Image Pin when Windows starts」を有効化 |
| クリック透過解除 | Hubから対象画像の設定を解除 |
| 完全終了 | Hubの「Exit」またはタスクトレイ |

Hubの**Images**タブで未表示画像を含む登録画像を管理し、**Imports**タブで名前付きURL画像を保存・表示・再取得できます。表示枚数には未表示の登録を含めません。

## グループと復旧

グループ内のどの画像からでも全体を移動・拡縮できます。画像サイズと画像間隔が一緒に変わり、回転した画像でも`Ctrl`は画面上の横方向、`Alt`は縦方向に作用します。通常の拡縮では、いずれかの画像が倍率上限・下限に達すると全体を止め、縦横比を保ちます。複製した画像は単体で追加されます。

グループ情報も次回起動時に復元されます。画面外からの救出はグループ全体を同じ距離だけ移動します。画面より大きいグループでは、並びを保ちながら一部を操作できる位置へ戻します。

USB未接続や画像破損などで読み込めない場合も、登録と配置情報は「Unavailable」として残ります。ファイルが使えるようになったら「Retry」、ファイルを移動した場合は「Change」、登録自体が不要なら「Remove」を使ってください。元ファイルが消えた後に複製しても、エラーを表示してアプリの動作を継続します。

## 保存データ

```text
%LocalAppData%\DesktopImagePin\images.json
%LocalAppData%\DesktopImagePin\images.backup.json
%LocalAppData%\DesktopImagePin\url-imports.json
%LocalAppData%\DesktopImagePin\ImportedImages\
```

変更は操作停止から約1.5秒後と通常終了時に保存します。復元途中では自動保存を行いません。`images.json`と`images.backup.json`にはローカルファイルパスが含まれるため、公開Issueへ添付する際は個人情報を削除してください。

保存内容の項目や数値を検証し、不正な場合はバックアップから復旧します。破損した主ファイルで正常なバックアップを上書きしません。グループ情報がない以前の保存形式も読み込めます。

自動起動設定を有効にした場合は、現在のユーザーの以下のレジストリ値にEXEパスを保存します。

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DesktopImagePin
```

EXEを移動した場合は、新しい場所のEXEで自動起動を有効にすると登録先を更新できます。

## 開発と保守

このプロジェクトは小規模なWindowsユーティリティとして継続保守します。安定性、分かりやすい操作、安全なローカル保存、依存関係を増やしすぎないことを優先します。今後の予定は[ROADMAP.md](ROADMAP.md)とGitHub Issuesで管理します。
